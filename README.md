## ✨ نبذة

UniVerse موقع جامعي متكامل يجمع الموقع التعريفي مع الأنظمة الرقمية (التقديم، التسجيل، البوابة، التعلم الإلكتروني) في تجربة واحدة سلسة. اتبنى كمشروع تخرج في Modern Academy، بتصميم مؤسسي هادئ ولون قرمزي واحد، وكل صفحة متوفرة بالعربية والإنجليزية بقلب كامل للاتجاه.

## 🚀 أهم المزايا

- 📝 تقديم إلكتروني بمعالج من 5 خطوات، تحقق لحظي، مراجعة قبل الإرسال ورقم طلب
- 🎟️ تسجيل في الفعاليات مع رقم حجز
- 📚 دليل مقررات بالبحث والفلاتر ومتطلباتها السابقة
- 🧮 حاسبات الطالب: المصروفات، المعدل، حد الساعات، حالة الغياب
- 🗓️ تقويم أكاديمي وجدول الامتحانات
- 🧑‍🎓 بوابة الطالب، نظام التعلم LMS، والمعاملات الإلكترونية Paperless
- 🔬 البحث العلمي والمنشورات، الخريجون والوظائف
- 🔎 بحث فعلي داخل الموقع كله

## 🌍 اللغة والإتاحة

- تبديل عربي/إنجليزي بحفظ الاختيار وقلب RTL/LTR
- وضع التباين العالي، التحكم في حجم الخط، وتخطي للمحتوى
- حالات تركيز واضحة واحترام تقليل الحركة

## 📱 الموبايل

- قائمة جانبية بأكورديون وروابط سريعة
- مفيش تمرير أفقي على أي صفحة (اتجرب على 360 و390 و414 و768)
- الجداول الواسعة بتتحرك داخل بطاقتها بس
- زر "قدّم الآن" بيختفي وانت بتنزل

## 🗂️ هيكل المشروع

```
UniVerse/
├── index.html        نقطة الدخول
├── landing.html      الرئيسية
├── *.html            الصفحات العربية
├── en/               النسخة الإنجليزية بنفس الأسماء
└── assets/           الستايل والخطوط والصور
```

## ▶️ التشغيل

1. حمّل المشروع وفك الضغط
2. افتح `index.html` بنقرة مزدوجة
3. لا يحتاج أي خادم أو تثبيت

## 🧱 قاعدة البيانات

الحقول والبيانات مبنية على الـ ERD الخاص بالفريق: المقررات، سعر الساعة لكل دفعة، حدود الساعات، أنواع الطلبات، وبيانات الطالب.

## ⚠️ ملاحظة

الموقع واجهة أمامية بالكامل ببيانات تجريبية، ولا يوجد خادم بعد.
